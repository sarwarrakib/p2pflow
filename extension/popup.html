Binance C2C CRM Collector

Connect this extension to Manual P2P Desk CRM. It listens for SELL order P2P Info clicks, collects missing counterparty Trade Info/Feedback only when CRM asks, posts it back, and closes the Binance tab automatically.

Manual test tools
Safety notes

This extension only reads visible Binance page DOM after opening the advertiserDetail page. It does not read cookies, passwords, tokens, localStorage, or sessionStorage. Login/CAPTCHA/security checks must be completed manually in your browser.
